# Contract Change Requests

`src/rag/core` is frozen after Step 0. If a module needs a change to core
(models, interfaces, config, fakes), do not edit core. Append a request below,
use a local workaround, and keep going. Requests are reviewed at merge time.

## Template

```
### <short title>
- Requested by: <module>
- Date: YYYY-MM-DD
- Change: <what should change in core>
- Why: <what breaks or is awkward without it>
- Workaround in place: <what you did instead>
```
